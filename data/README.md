# Orders Explorer: take-home data

Data for the Orders Explorer take-home assignment.

| File | What it is |
|------|------------|
| [`orders.json`](./orders.json) | About 50,000 order records, about 17 MB. |
| [`data-notes.md`](./data-notes.md) | What each field means, the known problems in the data, and what to do about each one. |

Download both files with **Code → Download ZIP**, or clone the repository:

```bash
git clone https://github.com/Juni-juns/orders-explorer-data.git
```

Read `data-notes.md` before you start. Do not edit `orders.json`.
